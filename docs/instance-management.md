# 新建 Sunshine 实例

1. 点击「新建实例」，只输入实例名称（最多 32 个 Unicode 字符）。
2. 页面给出配对码、Manager ID 和设备 ID。配对码不设有效期，仅本次显示，请安全保存。
3. 在 Sunshine 主机按 Agent 安装手册填写受保护的 bootstrap.json，将配对码填入 enrollment_token。Sunshine 密码只留在 Agent 本机。
4. Agent 使用可信 HTTPS 注册并建立 WSS 通道。配对码完成一次绑定后立即失效，后续使用独立设备凭据。
5. 未配对时可点击「取消配对」并确认。取消使配对码永久失效，但保留实例和审计记录；若要重新配对，请新建实例。

没有独立的邀请、重新生成注册票据入口或配对码有效期设置。刷新后不能找回配对码；丢失时取消并重新创建。

取消配对与注册在数据库事务中互斥。已配对的设备使用「撤销设备凭据」，不能用取消配对代替撤销。Agent 在线、Sunshine 可访问、配置生效状态仍分别展示。

本次只调整当前数据库合同，不清空、迁移现有运行数据，也不增加旧格式兼容。
