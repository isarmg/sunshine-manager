# Sunshine Manager Server v0.10.0

为 [Sunshine Client v0.1.0-rc.3](https://github.com/isarmg/sunshine-manager-client/releases/tag/v0.1.0-rc.3) 提供简化配对的配套预发布版本。

- 新增受可信 HTTPS 入口约束的 `/sunshine-client/v1/pairing`，用户只需输入 Server 地址和配对码，不必抄写 Manager / 设备标识。
- 配对码查询不消费令牌，实际注册仍原子单次绑定；已取消、已撤销或已注册的令牌拒绝使用。配对码无自动有效期，可在管理页自行取消。
- 管理任务由本机独立 Client 执行，Server 不集中保存 Sunshine 管理密码；保留管理员认证、权限、任务持久化和审计。
- Web 分别显示 Client 在线、Sunshine 可达和配置状态；保存、待重启、待验证不等同于运行时生效。
- 保留统一中英文 Web、实例表格、顶部图标工具栏及行内登录校验。
- 修正发布清单对当前数据库 schema revision 6 的校验，并加入回归测试。

## 部署与校验

Server 附件为 Ubuntu 24.04 x86_64 构建的 `sunshine-manager-0.10.0-x86_64-unknown-linux-gnu.tar.gz`，包含二进制、管理 Web、systemd unit、运维说明和逐文件发布清单；不需要相邻源码仓库。
先检查附件 `.sha256`，按归档内 README 部署到只读 `releases/0.10.0` 目录，运行 `verify-release` 后再启动。完整源码 SHA、版本与 schema 指纹绑定在制品身份中。

生产环境必须使用可信 HTTPS/WSS 反向代理。Client 仅接受系统已信任、名称匹配且有效的 Server 与本机 Sunshine 证书；不提供 TLS 绕过。Sunshine 配置适配固定为官方 `v2026.516.143833`。

使用全新当前数据库，不支持旧数据库升级、覆盖或兼容转换。备份恢复与升级继续由 `sarmg-upgrade` 的明确支持矩阵决定，不得套用旧版本适配器。

发行门禁包含 Server Rust/协议测试、Web 构建与浏览器测试、独立构建检查，以及标签归档的清单校验、异地解包启动和篡改拒绝测试。
配套 Client 仍为候选版本，尚未完成该候选版本的真实 Sunshine 重启验收；本次配套 Server 同样标记预发布，不扩大既有验收声明。
