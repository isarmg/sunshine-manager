# Sunshine Manager Server v0.10.1

配套 [Sunshine Client v0.1.0-rc.4](https://github.com/isarmg/sunshine-manager-client/releases/tag/v0.1.0-rc.4) 的预发布版本。

- 为 `sunshine-management/1` 协议增加真实 macOS Intel 与 Apple Silicon 平台值；Windows/Linux 协议行为保持。
- 将产品版本、Web 版本、发布清单、systemd 路径及归档身份统一为 0.10.1，schema revision 仍为 6。
- 发布构建绑定主分支上的完整源码 SHA 和 annotated 标签，并执行清单校验、异地解包启动与篡改拒绝测试。

附件 `sunshine-manager-0.10.1-x86_64-unknown-linux-gnu.tar.gz` 在 Ubuntu 24.04 x64 构建，包含独立 Server、Web、systemd unit、运维说明与逐文件清单。核对 `.sha256`，按归档 README 部署到只读 `releases/0.10.1` 并先运行 `verify-release`。生产入口要求可信 HTTPS/WSS，Sunshine 适配版本为 `2026.516.143833`。

本次没有执行生产部署；连接 macOS Client 前须先部署匹配 Server。不声明支持旧数据库自动升级/转换，也不新增未经验证的 `sarmg-upgrade` 迁移边。配套 Client 尚未完成 Linux/macOS 真实 Sunshine、受控写入重启以及物理重启后无人登录的全套验收，因此保留预发布标记。
